# ProdCollab — Lovable UI Prompt
### Complete product UI generation prompt. Every screen, every state, every modal.

---

## PASTE THIS INTO LOVABLE:

---

Design the complete UI for ProdCollab — a dark, luxurious desktop application 
for music producers that combines real-time collaboration, automatic cloud backup, 
version control, and session management. Think of it as GitHub meets a studio 
console. Producers use it to back up their work automatically and collaborate with 
other producers in real time across any DAW.

---

## VISUAL FOUNDATION

Base color: pure black #000000.
Choose all other colors yourself based on what complements pure black.
Maximum 2 accent colors beyond black. One for primary actions and presence.
One for status/success states. Let everything else live in dark greys.

Typography: modern, tight letter-spacing, clean hierarchy.
Large project names. Small metadata. Never rounded or bubbly.
Cards: 1px subtle borders, barely visible against black.
No heavy shadows. Depth through layering and opacity.
Spacing is generous. Darkness breathes.
The product should feel like opening a high-end studio at 2am.
Not a SaaS dashboard. A space.

## DESIGN RULES — DO NOT BREAK THESE

- Base is pure black #000000. Never use dark grey as the base.
- Presence dots are the only elements that should immediately pop with color.
- Green means live and active. Only use it for that.
- Left border color on project cards is the fastest signal of card state:
  Neutral dark = solo. Green = collaboration live. Amber = idle. Red = error.
- The session story timeline is the emotional heart of the product —
  it should look beautiful, not like a git log.
- Every destructive action (delete, leave) requires an extra confirmation step.
- Sync state is always visible. Producers need to know their work is safe.
- The video call overlay never takes over the full screen.
  Producers see their project while on the call.
- Push voice notes attach to pushes — they are not a chat system.
- "Start Session" (video call) should never feel like Zoom.
  It's a talkback channel, not a meeting room.

## WHAT THIS PRODUCT IS NOT

Not a streaming platform.
Not a plugin marketplace.
Not a DAW.
Not a chat app.
Not Slack for producers.

It is: a studio-grade collaboration layer that sits invisibly between
a producer's DAW and their collaborators. So minimal it disappears.
So reliable they forget it could fail.
So beautiful they open it on purpose just to see the session story.
